# OTP CENTER（干净版）

自有业务验证码中心：验证码由本站服务端生成，绑定订单与顾客，默认 5 分钟过期、一次性核销、每订单每小时限次，顾客之间数据隔离，管理员后台含总览 / 顾客 / 订单 / 验证码记录 / 核销 / 审计日志 / 系统设置。

不导入任何第三方邮箱凭据（密码 / Client_ID / Refresh_Token），不读取任何外部邮箱。

## 运行

无第三方依赖，Python 3 标准库即可：

```
PORT=8080 python app.py
```

首次打开页面 → 管理员后台 → 设置管理员口令（至少 6 位）→ 建订单（系统同时生成订单号+取码口令，只显示一次）→ 把订单号+取码口令发给买家 → 买家在首页凭这两样免注册取码 → 管理员在后台核销。口令在库里只存哈希，丢了可在订单列表点「重置口令」；口令连错 10 次锁定 10 分钟。

## 部署

- Railway / Render：连接本 GitHub 仓库，启动命令 `python app.py`（已带 Procfile），平台自动注入 PORT。
- 数据存 SQLite 文件 `otp.db`（可用环境变量 OTP_DB 指定路径）；平台磁盘不持久时数据会随重启丢失，正式使用请挂持久卷或换外部数据库。
